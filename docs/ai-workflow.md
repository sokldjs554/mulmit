# AI 코딩 에이전트와 일하는 방식

이 저장소는 AI 코딩 에이전트(Claude Code)를 개발 흐름에 넣어 만들었습니다. 에이전트에게 맡긴 것과 사람이 확인해야 하는 것을 나눠 기록합니다.

## 흐름

1. **조사 → 결정 기록**: 시장·데이터 소스 조사 결과를 [research](research/market-landscape.md)에, 되돌리기 어려운 선택을 [ADR](adr/README.md)에 먼저 남깁니다. 이후 작업 지시는 "ADR-0004대로"처럼 문서를 가리킵니다.
2. **정답이 있는 루프**: 합성 세계와 평가 러너를 초기에 만들었습니다. 파서·프롬프트·연결 규칙을 바꾸는 작업은 모두 "`manage eval all` 수치가 어떻게 바뀌었나"로 끝납니다. 예: 연결 재현율 0.70 → 동의어 사전·정규화·배타성 가산 → 1.00, 규모를 키웠을 때 생긴 오병합(스마트쉘터↔스마트폴) → 구체 사업명 충돌 감점.
3. **타입과 계약으로 경계 고정**: mypy strict, Pydantic 스키마, OpenAPI → TypeScript 생성 타입. 에이전트가 한쪽을 바꾸면 CI가 다른 쪽의 불일치를 잡습니다.
4. **실제 인프라로 테스트**: 통합 테스트는 모킹 대신 PostgreSQL(pgvector)·Redis 서비스 컨테이너에서 Alembic 마이그레이션부터 돌립니다. 동시 크레딧 사용, 알림 중복, 결제 멱등성 같은 "그럴듯하지만 틀리기 쉬운" 부분이 여기서 걸립니다.
5. **화면은 직접 본다**: Playwright로 주요 화면을 캡처해 라벨 겹침·차트 축 글자 크기·중복 문구 같은 시각적 결함을 확인하고 고쳤습니다(`docs/screenshots/`).

## 에이전트용 지침

루트의 [`AGENTS.md`](../AGENTS.md)(Claude Code는 `CLAUDE.md`로 읽음)에 명령어, 코드 규칙, 금지 사항(정답 데이터 누수, 테스트 건너뛰기 등)을 적어 두었습니다. `apps/web/AGENTS.md`는 Next.js가 생성한 버전별 안내입니다.

## 사람이 확인해야 하는 것

- **외부 명세**: 공공 API 경로·필드는 개발 컨테이너에서 직접 호출할 수 없어 공개 명세 기반으로 작성했습니다. 첫 실키 실행은 사람이 봐야 합니다.
- **LLM 실호출 품질**: 실제 API로 수기 세트를 돌리는 측정(`make eval-llm`, GitHub Actions **LLM eval**)은 비용이 드므로 사람이 키와 상한(`--max-usd`)을 정해 실행합니다. 첫 실행 결과는 [evaluation-llm.md](evaluation-llm.md). 에이전트가 짠 금액 파서의 버그를 이 측정이 찾았습니다(#10). 정답이 있는 루프가 사람의 검토를 대신하지는 않지만, 무엇을 봐야 할지는 알려 줍니다.
- **법·약관**: 공공누리 유형, 회의록 발언자 개인정보(실명) 표시 범위, 전자금융·자동결제 약관.
